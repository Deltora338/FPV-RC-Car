This project was completed for 91907 & 91904 NCEA assesments (complex techniques and electrical systems)

For this project the minimum viable product was a remote control car, that had a mounted camera, which was able to be viewed from computer or headset.

Sprint 1 - Researching and ordering components and software

Sprint 2 - Construction of car and writing the software for the control of the car

Sprint 3 - Improving the car's software as well as the pysical condition of the car and implementing video feed
